# UTT D-2 화면 코드 — 제한적 인계 후보

상태: SOURCE_REVIEW_PARTIAL. 이 디렉터리는 D-2의 기존 사용자용 화면 코드 일부를 검토용으로 분리한 것으로, 완전한 실행 앱이 아닙니다. 운영 자료가 없는 상태에서 임의의 앱을 새로 만들어 기존 기능이 검증됐다고 주장하지 않습니다.

## 자동 실행 봉쇄와 수정
모든 JavaScript 파일은 `.mjs.reference.txt` 확장자로 보관해 브라우저에서 자동 실행되지 않습니다. HTML에서는 script 요소를 제거하고 네트워크 연결을 허용하지 않는 CSP와 참고용 표시를 추가했습니다. A의 사용자 관련 검색 예시와 D-2의 특정 시점 건수, C의 고정 파일 크기 및 특정 시점 건수는 제거했습니다. 기존 JS에는 요청·저장·복원·초안 생성 동작의 참조 코드가 있으므로 개발자가 그대로 연결하거나 사용해서는 안 됩니다. 정적 HTML의 버튼은 작동하지 않습니다. 과거 화면의 상태 문구는 당시 설계 흔적일 뿐 현재 검증 결과가 아닙니다.

## 의존성 및 제외 사항
원본 A는 `app/Start_Reader.cmd` → `tools/serve_local.py --auth` → `web/index.html` → `web/app.mjs` → `web/worker.mjs`·`web/lib`·Dropbox SDK의 구조입니다. 원본 C는 `Start_Gate_C11.cmd` → `app/gate_c/server.py` → `app/web/gate-c/index.html`, D0/D1/D11/D2는 각각 해당 시작 스크립트 → Python 서버 → 해당 `web` 화면 구조입니다. 원본 런타임은 Python 3.11 이상과 모듈을 지원하는 브라우저를 사용하며 일부 자동 검증에는 Node.js가 필요합니다. 별도의 패키지 잠금 파일은 확인되지 않았습니다.

원본 A 설정에는 실제 App Folder 연결 설정과 키, 사용자 승인 기준 카탈로그가 있고 서버 시작 인자는 인증 기능을 활성화합니다. 이를 개발 기본값으로 가져오지 않기 위해 config, 카탈로그, vendor, worker, 인증·복원·캐시 코드 및 서버·시작 스크립트를 제외했습니다. D 계열 서버는 원장 경로, 실제 DB 및 승인·백업·쓰기 동작에 결합되어 있어 이번에 함께 제외했습니다. 실제 DB, 원문, 원장, 입력 ZIP, 이미지·보고서·실제 자료에 의존하는 테스트도 제외했습니다. 원본은 Work 쪽에 보존합니다.

## Codex의 다음 단계
합성 자료만 반환하고 명시적 실패를 표현하는 데이터 어댑터를 새로 연결합니다. 참조 JS를 복원할 때 읽기·쓰기 작업을 분리하고 부주의한 업로드, 원장 쓰기, 자동 복원·인증·캐시 접근을 봉쇄한 뒤 검토된 계약에 맞춥니다. 먼저 합성 환경에서 검색·상세·필터·페이지 UI를 검증하고, 기존의 결정·백업·승인 기능은 별도 명령 계약이 마련될 때까지 연결하지 않습니다.

실행 재개 전 확인: 빠진 worker/lib/server 의존성을 데이터와 분리해 검토, ID·카탈로그·실제 기준값 제거, 합성 어댑터를 통한 코드 경로 시험, 테스트 및 비밀·데이터 스캔, 계약 검토. 그 전에는 이것을 기존 프로그램 완전 복구나 실제 DB 접합으로 판정하지 않습니다.

## 순수 읽기 모듈 별도 인계

`safe_modules/readmodel`의 4개 파일은 원본과 바이트 동일합니다. 이 함수들은 인자로 받은 데이터만 처리하며 기본 경로·네트워크·원장·캐시 접근을 포함하지 않습니다. `ReadModel.search` 및 UTF-16 좌표 파서, 정규화 검색 인덱스와 canonical 화면 변환을 합성 자료에서 시험합니다. 기존 READMODEL-1 전용 의미이므로 신규 인계 계약과 자동 호환된다고 추정하지 말고 어댑터에서 확인해야 합니다. 특히 기존 검색은 전체 입력을 메모리에서 처리하고 오프셋 페이지를 사용하므로 대규모 스트리밍·스냅샷 일치 문제는 후속 구현에서 해결해야 합니다.

`node --test tests/pure_legacy_synthetic.test.mjs`는 이 모듈에만 적용되는 가상 입력 시험입니다. 기존 전체 앱 실행이나 실제 데이터 접합 시험이 아닙니다.

### 운영 데이터 적용 금지 및 확인된 제한

`baselineDataset()`은 독립적인 기준본 검증을 수행하지 않으면서 반환 객체에 검증을 암시하는 고정 문구를 넣습니다. 이 문자열을 검증 증거로 사용하거나 현재 원격 기준본이 확인됐다고 표시하면 안 됩니다. `fromBaseline()`은 입력 전체를 메모리에 모으고 기존 규칙으로 관계와 그룹을 파생하므로 현재 접합 계약과 대규모·불확정 관계 요구를 충족한다고 보장하지 않습니다. **이 네 모듈은 합성 자료만 사용할 수 있는 구버전 참조 코드**로 한정하고, 실제 데이터에 적용하지 마세요. 실데이터 접합 이전에 해당 동작을 교체·검토하고 근거 기반 검증 및 비파괴·페이징 시험을 별도로 수행해야 합니다.
