# 검토된 인계 원형

`handoff-v1/`는 사용자 제공 코드 전용 ZIP을 지정된 SHA-256으로 검증한 후 원본 바이트를 직접 복사한 기준 사본입니다. 현재 작업트리로 재구성하지 않았습니다. 매니페스트 자신의 해시는 파일 목록에서 제외되며 도구가 별도로 고정한 SHA-256으로 검증합니다. ZIP 출처는 handoff-v1-origin.json을 참고하세요.

이 사본을 수정·import·실행·시험 탐색·HTTP 제공·배포하지 않습니다. 개발은 루트의 활성 소스에서 합니다. 지원 시험 명령은 명시한 활성 루트만 탐색합니다. Git export-ignore와 Docker ignore에 provenance를 등록했습니다. 임의의 외부 배포 도구나 루트 무제한 탐색 명령까지 자동으로 통제한다는 뜻은 아닙니다.

`python3 tools/verify_handoff.py`가 원형 전체와 현재 작업트리를 독립 검사합니다. 원형 매니페스트나 제외 목록을 수정해 차이를 숨기지 마세요. 실제 DB·자료·Work 전용 패키지·비밀은 이 경로에도 보관하지 않습니다.
