# UTT 합성 읽기 프로그램 구현 및 응답·인계·초점 회귀 보완

기존 부분 인계에는 실행 서버·worker·인증이 없어 사용자 흐름을 실행할 수 없었습니다. 이 브랜치는 `6520dc1`의 Python/ES modules 합성 프로그램 구현을 포함하고, 응답 dataset/snapshot 검증 결함과 관련 자료 이동 뒤 목록 초점 복귀 결함을 보완합니다. main 대상 검토 범위에는 최초 구현과 보완이 함께 들어갑니다.

전송한 요청 범위로 응답 봉투·내부 자료를 검사하여 다른 dataset/same snapshot 응답을 거부합니다. 초기 capabilities의 null 범위도 내부 일관성은 검사하며, UI 요청 세대 검사를 유지합니다. 목록의 최초 선택과 현재 상세를 분리해 2페이지 이력→관련 자료→복귀 시 원래 버튼으로 초점을 돌립니다.

사용자 제공 코드 전용 ZIP의 SHA-256을 대조한 뒤 `provenance/handoff-v1/`에 원형을 직접 보존했습니다. 원형 38개를 제외 없이 검증하고, 현재 개발본의 의도된 변경·누락·설명 없는 변경을 분리합니다. `.env.example`을 복구하고 `.gitignore`는 원본 규칙에 개발 산출물 규칙만 추가했습니다. 사본은 HTTP·지원 시험 탐색·배포 입력에서 제외합니다.

로컬 검증: Python 23개, Node 20개, Draft 2020-12 합성 요청/응답 61회, Chromium 연속 흐름 13개 묶음 통과. 기존 7,000건·70페이지 시험과 기존 검증을 보존했습니다. 기준 코드에서 응답 회귀 9건 실패와 관련 자료 복귀 초점 누락을 실제 재현했습니다. 자세한 변경·재현·도구 버전·실패/미수행은 docs/REMEDIATION_20261104.md에 있습니다.

실제 DB·원문·원장·캐시·비밀·운영 API 자료는 사용하지 않았습니다. 실제 연결·운영 승인·Windows 수용·실제 규모·CI는 미수행이며 운영 배포·병합을 요청하지 않습니다. C 미리보기·D-1.1 원장 명령·D-2 영향 분석 등 미지원 범위의 추가 코드·계약·담당·시험은 Work 접합 메모에 구분했습니다.
